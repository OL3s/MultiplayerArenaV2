# Game Concept

This document tracks the high-level game direction.

## Core Concept

- Top-down 2D arena shooter.
- Simple movement and combat controls.
- Small arena-based matches.
- Multiple game modes.
- Fully destructible environments.
- Quick rounds and multiplayer-focused gameplay.

## Planned Game Modes

- `Deathmatch`
- `CaptureTheFlag`
- Free-for-all is not a separate mode in the current design. A deathmatch setup with one player per team covers the same gameplay shape for now.
- More modes may be added as the core gameplay develops.

## Current Direction

The game should prioritize fast readable combat, local/online multiplayer flexibility, and destructible arena play. Systems should remain generic enough for multiple themes, including the current modern item direction and possible future medieval content.
